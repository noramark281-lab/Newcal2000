## 🌟 ميزات وأقسام التطبيق الرئيسية

### 1. 🗂️ قسم عام (المرضى والمعالجات)
- تسجيل وحفظ بيانات المرضى:
  - اسم المريض ورقم الهاتف.
  - نوع الحالة (حشو عصب، حشوة ضوئية، قلع جراحي، تنظيف وتبييض، زراعة أسنان، تركيبة ثابتة، تقويم، علاج لثة...).
  - إجمالي المبلغ، الواصل (المدفوع)، والمتبقي (الديون) تلقائياً.
  - التاريخ واليوم وملاحظات التشخيص والمعالجة.
- **إرسال رسائل تذكيرية بنقرة واحدة عبر واتساب** أو الاتصال الهاتفي المباشر بالرقم.
- **تصدير كشف حساب المرضى إلى PDF رسمي للطباعة أو Excel (CSV)**.

### 2. 🔬 قسم المعمل (طلبيات وتركيبات الأسنان)
- تسجيل طلبيات معمل الأسنان:
  - اسم المعمل ورقم الهاتف.
  - نوع العمل (زركونيا Zirconia، إيماكس E-Max، بي اف ام PFM، طقم أكريليك، طقم كاست، فينير...).
  - عدد الأسنان واللون (Shade: A1, A2, A3, BL2...).
  - تاريخ الإرسال وتاريخ الاستلام المحدد.
  - إجمالي التكلفة، المسدد للمعمل، والمتبقي.
- إرسال رسائل تذكير ومتابعة للمعمل عبر واتساب وتصدير تقارير PDF وإكسل.

### 3. 📦 قسم المواد (فواتير ومستلزمات العيادة)
- متابعة مشتريات وفواتير موردي ومحلات مواد الأسنان:
  - اسم المحل / المورد ورقم الفاتورة.
  - نوع المواد (تخدير موضعي، كمبوزيت ومواد حشو، مبارد روتاري وإندو، مطاط طبعات، معقمات...).
  - إجمالي الفاتورة، المدفوع، والمتبقي.
- مطابقة الفواتير مع الموردين عبر رسائل واتساب وتصدير PDF وإكسل.

### 4. ⚖️ مصادقة الرصيد والتدقيق المالي
- كشف حساب وتدقيق مالي شامل:
  - إجمالي إيرادات العيادة.
  - إجمالي المقبوضات النقدية (الكاش الفعلي).
  - إجمالي ديون المرضى المعلقة (لنا).
  - إجمالي مستحقات المعامل ومصروفات المواد (علينا).
  - **صافي السيولة والأرباح النقدية المتوفرة بالعيادة**.

### 5. 📈 التقارير والإحصائيات
- مؤشرات بصرية ونسب مالية لمصروفات المعامل والمواد مقابل الدخل، وإحصائيات الحالات الأكثر تسجيلاً.

### 6. ⏰ التذكيرات والمتابعة

## 🛠️ البناء الآلي والتحميل عبر GitHub Actions (Workflow)

تم تضمين ملف **GitHub Actions Workflow** في المسار `.github/workflows/build-apk.yml`.

### 📥 كيفية الحصول على رابط تحميل ملف الـ APK المباشر من GitHub:

1. اذهب إلى صفحة مشروعك على **GitHub**.
2. اضغط على تبويب **Actions** في الشريط العلوي للمستودع.
3. ستجد سير العمل باسم **Build Android APK**.
4. عند الضغط عليه، ستجد زر **Run workflow** (يمكنك تشغيله يدوياً أو سيبدأ تلقائياً عند أي Push).
5. بعد انتهاء عملية البناء (تأخذ حوالي دقيقة إلى دقيقتين):
   - ادخل على جلسة البناء المكتملة بعلامة صح خضراء `✔`.
   - انزل إلى قسم **Artifacts** في أسفل الصفحة.
   - ستجد ملف: **`AlRahman-Clinic-APK`** جاهزاً للتحميل المباشر بصيغة `AlRahman-Clinic-v1.0.apk`.
   - قم بنقله وتثبيته مباشرة على هاتفك أندرويد.
